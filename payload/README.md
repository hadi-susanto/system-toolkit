# 📦 SysKit Payloads

This directory contains the payloads used by SysKit command scripts. These are
the source files that the scripts install, activate, or otherwise manage on the
system.

Payloads are organized by toolkit:

- `bin/` contains standalone executable scripts.
- `config/` contains configuration and preference assets.
- `shell/` contains shell integration modules.

Executable command routing belongs under `command/`, and reusable sourceable
functions belong under `lib/`.
